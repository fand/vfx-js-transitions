Presets

Every preset in @vfx-js/transitions, grouped by what it suits. Pass one as transition. Presets with options also have a create* factory.

For page navigation

Calm and short. The text stays readable, so they suit routes you click often.

gl-transitions

createGLTransition turns any shader from gl-transitions into a transition. Look one up by its name. Shaders that need extra textures are not supported.

Try them all in the Playground, under the gl-transitions tab.

cube.ts
import { createGLTransition } from "@vfx-js/transitions";
import transitions from "gl-transitions";

const cube = transitions.find((t) => t.name === "Cube")!;
t.run(swap, { transition: createGLTransition(cube, { persp: 0.5 }) });
