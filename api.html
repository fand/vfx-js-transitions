API Reference

Core works on any element. The React bindings wrap it for routers. Presets live in @vfx-js/transitions.

vfx.addTransition(element, opts?)

From @vfx-js/core. Returns a TransitionHandle at once. It touches no DOM until the first run.

core
import { VFX } from "@vfx-js/core";
import { swipe } from "@vfx-js/transitions";

const vfx = new VFX();
const t = vfx.addTransition(el, { transition: swipe, duration: 0.6 });
transition: TransitionDef
The shader. Defaults to crossfade.
uniforms: TransitionUniforms
Uniforms for transition. Numbers and vectors.
duration: number
Seconds. Defaults to 0.6. 0 cuts without animation.
reverse: boolean
Play backwards. readFrom and readTo swap in the shader.
ease: "smoothstep" | "linear" | (x) => t
How t follows progress. Defaults to the def's ease, then smoothstep.
overflow: true | number
Room to draw outside the element. true for the whole canvas, a number for CSS px on every side.
keepWrapped: boolean
Keep the element wrapped between runs. Saves the wrap cost on frequent runs.
waitFor: "media" | "none" | (el) => Promise<void>
What to wait for before the new capture. "media" waits for images, videos and fonts, up to about 300 ms.

TransitionHandle

A new run during a run drops the old one. Its callback still runs, so no DOM change is lost.

show(slide, opts?)
Shows one direct child and hides the others. slide is an element, an index or a selector. remove: true removes the others instead.
run(cb, opts?)
Snapshots the element, calls cb to change the DOM, and plays the transition. Resolves when the animation ends.
cancel()
Ends the current run and shows the live content.
destroy()
Cancels and stops tracking the element.
running
True while a run is in flight.

RunOpts

Each field comes from the first level that sets it: the run, then the container, then the def (for ease).

run
t.run(() => render(next), { transition: glitch, reverse: true });
transition, uniforms, duration, reverse, ease, overflow
Same as the container options. A run's value wins.
uniforms
Merge per key, run over container. A run with its own transition drops the container's uniforms.
opts as a function
Called once after cb resolves, so the spec can depend on the new content.

<VFXTransition>

From @vfx-js/react. Wrap the router outlet once. Next.js users import it from @vfx-js/react/next, where pageKey defaults to the pathname.

layout.tsx
<VFXTransition pageKey={pathname} transition={crossfade} duration={0.6}>
  {children}
</VFXTransition>
pageKey: string | number
Changes per page, e.g. the pathname. A new key starts a run.
fullscreen: boolean
Defaults to true: the target is 100dvh tall and scrolls inside. false lets your CSS size it.
className, style
Go on the inner div, which is the transition target.
...addTransition options
transition, duration, ease, overflow and the rest, as defaults for every run.

<TransitionIn> and useTransitionIn

The incoming page says how it enters. Only the spec at mount counts. Use the component in Server Components and the hook in client components.

page.tsx
<TransitionIn transition={glitch} />
// or, in a client component:
useTransitionIn({ transition: glitch });

transition(spec)

Returns an onClick that stores the spec for the next run. It wins over the page's <TransitionIn> and expires after about 10 s. It ignores modified and non-left clicks.

link.tsx
<Link href="/about" onClick={transition({ transition: glitch })}>About</Link>

useVFXTransition(opts?)

For containers you render yourself, like tabs. run wraps cb in startTransition and starts after React commits.

tabs.tsx
const { ref, run } = useVFXTransition({ transition: swipe });

<div ref={ref}>{tab}</div>

await run(() => setTab(next), { reverse: true });

setNextTransition(spec)

For navigation from code. Like a click spec, it wins over the page.

navigate.ts
setNextTransition({ transition: zoom });
router.push("/next");

TransitionDef

What every preset is. Most are one shader, made with shaderTransition. See Custom for effects.

name: string
A name for logs.
ease?: TransitionEase
The t this transition expects. A spec's ease wins.
create(): TransitionEffect | TransitionEffect[]
Makes the effects for one container. Runs that keep the def reuse them.

shaderTransition(opts)

From @vfx-js/core. Wraps your frag with a prelude and a main.

name: string
A name for logs.
frag: string
GLSL that defines vec4 transition(vec2 uv, float t).
uniforms?: TransitionUniforms
Defaults. The spec's uniforms win.
ease?: TransitionEase
Defaults to "smoothstep".
overflow?: true | number
Room outside the element. The spec's overflow wins.
