Use with AI

The transition API is new, so coding agents don't know it yet. Give them the docs, and they can add transitions to your app or write new ones from a description.

Install the skill

The VFX-JS skill works with Claude Code, Codex, Cursor and other agents that read skills. Run this in your project.

It covers the presets, show and run, React, Vue, Svelte and Astro, custom transitions, and the pitfalls. The agent reads it when a task needs it.

terminal
npx skills add fand/vfx-js

Or use llms.txt

No skill support? Point the agent to llms.txt, or paste llms-full.txt into the chat. It has the same content as the skill in one file.

prompt
Read https://amagi.dev/vfx-js/llms-full.txt first.
Then add a Glitch page transition to this app.

Write a transition with AI

Describe the motion in words. Ask for a ShaderTransition, and the agent writes the frag.

Then paste the frag into the Playground and press Play. Tell the agent what to change, and paste again. The Playground has sliders only for its own examples, so ask for constants instead of new uniforms while you try it.

prompt
Write a VFX-JS ShaderTransition called InkBleed.
The new page spreads in like ink on paper, with a dark rim at the edge.
Use constants, not uniforms, so I can try the frag in the Playground.
ink-bleed.ts
import { ShaderTransition } from "@vfx-js/core";

export class InkBleed extends ShaderTransition {
  name = "ink-bleed";
  frag = `
const float EDGE = 0.08;

float hash(vec2 p) {
  return fract(sin(dot(p, vec2(127.1, 311.7))) * 43758.5453);
}
float noise(vec2 p) {
  vec2 i = floor(p);
  vec2 f = fract(p);
  vec2 u = f * f * (3.0 - 2.0 * f);
  return mix(mix(hash(i), hash(i + vec2(1.0, 0.0)), u.x),
             mix(hash(i + vec2(0.0, 1.0)), hash(i + vec2(1.0, 1.0)), u.x), u.y);
}

vec4 transition(vec2 uv, float t) {
  vec2 p = uv * vec2(resolution.x / resolution.y, 1.0) * 6.0;
  float n = (noise(p) * 0.5 + noise(p * 2.0) * 0.25 + noise(p * 4.0) * 0.125) / 0.875;
  float front = t * (1.0 + 2.0 * EDGE) - EDGE;
  float m = smoothstep(n - EDGE, n + EDGE, front);
  vec4 c = mix(readFrom(uv), readTo(uv), m);
  // Darkest where the ink is half spread.
  float rim = 1.0 - abs(m * 2.0 - 1.0);
  return vec4(c.rgb * (1.0 - rim * 0.6), c.a);
}
`;
}

Check the result

The agent writes the code but can't watch it run.

Console errors
A transition that fails to compile logs the error with line numbers in your frag, then cuts to the new content. Paste that log back to the agent.
Screenshots
Agents can't see the canvas. Ask for a Playwright script that clicks a link and screenshots mid-run. The browser needs WebGL.
Fixed size
If the page jumps after a run, the target's height changed. Ask the agent to fix the height of the target.
Reduced motion
Ask for duration: 0 when prefers-reduced-motion matches.
